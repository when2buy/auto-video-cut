# v0.1 — Silence Cut

> First feature. Implements approach **A** (silence-only, ffmpeg + auto-editor) from `_research.md`.
> Stage 1 of Approach D (Hybrid). Ships in <1 day, sets up the harness for Whisper + Gemini stages.

---

## Goal

`avc cut <input.mp4> --out <output.mp4>` removes silent segments from a video and concatenates the spoken parts, producing a tight cut **at least 25% shorter** than the input on a typical talk/lecture.

## Non-goals

- LLM-based content selection (that's v0.2 ASR + v0.3 Gemini)
- Visual / multimodal scoring (that's v0.4)
- B-roll generation, captions, face-zoom (post-v1)
- Real-time streaming (offline batch only)
- GUI (CLI only for v0)

## Acceptance

```bash
# unit + integration
pytest tests/ -v

# end-to-end smoke (requires sample.mp4)
avc cut tests/fixtures/sample-30s.mp4 --out /tmp/out.mp4 \
    --silence-threshold -30 --min-silence 0.5

# Verifiable assertions:
#  1. exit 0
#  2. /tmp/out.mp4 exists, is valid mp4 (ffprobe parses it)
#  3. duration(out) <= 0.75 * duration(in)   (at least 25% trim)
#  4. duration(out) >= 0.10 * duration(in)   (didn't kill everything)
#  5. output has both video AND audio streams (not just one)

python tests/check_e2e.py /tmp/out.mp4 tests/fixtures/sample-30s.mp4
```

The `check_e2e.py` script implements assertions 2-5 and exits non-zero on any fail.

## Decision

**Candidates considered**:

- **A. Wrap auto-editor**: install `pip install auto-editor`, shell out. 100 lines, works tomorrow.
- **B. Pure ffmpeg silenceremove filter**: one-liner `ffmpeg -af silenceremove=...`. 30 lines, but the filter is famously fragile on edge cases (cuts mid-syllable, video/audio drift on concat).
- **C. Custom librosa + ffmpeg**: detect silence in Python (RMS over frames), emit cut list, ffmpeg concat. 200 lines, full control.

**Chosen**: **A (wrap auto-editor)**

**Why**: auto-editor has 4 years and 4.3k stars of edge-case fixing — silence detection, video/audio sync, container quirks, all already handled. We get a working v0.1 today, and our code is just a thin CLI wrapper that calls auto-editor with sane defaults. When v0.2 needs ASR-driven cuts, we replace the auto-editor call with our own Whisper+Gemini pipeline, but keep the same CLI surface. C is over-engineering for v0; B is a footgun on real videos. Reversibility is trivial — auto-editor is one `subprocess.run` call.
